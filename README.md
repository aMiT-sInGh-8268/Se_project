# Se_project

Software Engineering Project repository.

## Automation
This repository includes automated sync & push capabilities:
- **`auto-push.ps1`**: PowerShell continuous file watcher that auto-commits and pushes changes to GitHub on file modification.
- **`auto-push.bat`**: One-click launcher for Windows.
- **Git Hook (`post-commit`)**: Automatically pushes commits to GitHub after each local commit.
